# ☕ Coffee Shop Website

Proyecto final de un curso de Desarrollo Web.  
Consiste en una página web responsive para una cafetería ficticia, diseñada para mostrar productos, identidad visual y experiencia de usuario.

---

## 🚀 Descripción

Este proyecto representa una landing page moderna para una cafetería, enfocada en un diseño limpio, responsive y bien estructurado utilizando tecnologías frontend básicas.

El objetivo fue aplicar conceptos fundamentales de HTML y CSS en un caso práctico.

---

## 🧩 Características

- Diseño responsive (mobile, tablet, desktop)
- Secciones estructuradas (Inicio, Nosotros, Productos / Menú, Contacto)
- Barra de navegación
- Uso de imágenes y tipografía para mejorar la UI
- Diseño limpio y simple

---

## 🛠 Tecnologías utilizadas

- HTML5
- CSS3
